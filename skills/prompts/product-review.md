# 产品审核 Prompt

## 审核标准

对每个待审核产品（status=1），按以下标准审核:

### 必须项（不满足则打回）

1. **产品名称** — 非空，无拼写错误，使用官方名称；不含 HTML 标签或装饰符
2. **链接** — links 数组至少1条；主链接（is_primary=true）须存在且指向产品官网；URL 不可达（HEAD 超时）应提示但非必须打回
3. **slug** — 与名称对应且 URL 友好；中文 name 应有拼音/英文 slug，不可为 `item-xxxx` fallback

### 建议项（不满足可通过但提示）

4. **分类正确性** — category_id 非空，且分类与产品功能匹配（如编程工具不应归到绘画类）
5. **定价正确性** — pricing 为合法值，且与实际相符（如标 free 但官网明示付费）
6. **描述正确性** — description 非空，且内容准确无错误；不含营销话术
7. **标签正确性** — tags 非空，且与产品特征贴切

### 审核原则

审核不仅看字段**有无**，更要校内容**对错**:

- 名称是否用官方名（"Chat GPT"→应"ChatGPT"）
- 分类归属是否合理
- 定价标注是否与实际一致
- 描述有无错误信息
- 标签是否贴切

### 审核结论

- **通过**: 所有必要项满足 → status=2（已发布）
- **打回**: 必要项缺失 → status=0（草稿），附具体打回原因

### 输出格式

```
审核结果:
  ✅ 产品名: ChatGPT (id=40)
     - 名称: ✓ 官方名
     - 链接: ✓ https://chat.openai.com (主链接, 官网)
     - slug: ✓ chatgpt
     - 分类: ✓ 对话助手
     - 定价: ✓ freemium（与实际一致）
     - 描述: ✓ 准确无营销话术
     - 标签: ✓ 贴切
     → 通过，已发布

  ❌ 产品名: Chat GPT (id=88)
     - 名称: ✗ 拼写错误（应为 ChatGPT）
     - 链接: ✓
     - slug: ✓
     → 打回，原因: 名称非官方拼写

  ❌ 产品名: 某工具 (id=89)
     - 名称: ✓
     - 链接: ✗ 无链接
     → 打回，原因: 缺少产品链接
```
